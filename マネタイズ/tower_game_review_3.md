# 第3回 辛口コードレビュー：はじっこ勇者のインフレ魔塔

**レビュアー:** 私（リードエンジニア 兼 パフォーマンス・音響監査人）
**対象バージョン:** v1.2.0 (第2回修正後)

2回目の修正によって、ゲーム進行の安全性（詰み防止）となぞり操作のReflow排除（カクつき根絶）が達成されました。最後のレビューとして、ゲームの安定動作の極限（数時間プレイし続けた際のエラー防止）および音響の心地よさを担保するため、以下のボトルネックを監査・指摘します。

---

## 🚨 重大な指摘項目

### 1. 【メモリリーク】フロア遷移時のイベントリスナー多重生成と破棄の脆弱性
*   **問題点:**
    現在の設計では、フロアに入る（`generateFloorData()`）たびに `buildGridDOM()` が走り、25個のパネルに対して個別に `pointerdown` のイベントリスナーを新規にアタッチしています。古いパネルは `innerHTML = ""` で破棄されていますが、JSのクロージャ（`pathTracker.start(i)`）が暗黙的にセルインデックスへの参照を抱え込んでいるため、長時間のプレイ（50階層の登頂と数十回のリトライ）によってメモリリーク（ガベージコレクションされずメモリ消費が肥大化する現象）を引き起こすリスクがあります。
*   **対策:**
    イベント委譲（Event Delegation）を導入します。各セルにリスナーを貼るのをやめ、親コンテナである `#grid-container` にイベントリスナーを**生涯で1回だけ登録**し、バブリングしてきた `pointerdown` の `e.target.closest('.grid-panel')` からインデックスを取り出して処理します。これによりメモリリークを100%根絶します。

### 2. 【音響】Web Audio API の切断時における「プチプチ」クリックノイズ
*   **問題点:**
    効果音の再生時（`AudioManager.playSound()`）やBGMのノートが停止する際、音量（Gain）がまだ完全に 0 になりきっていない状態、あるいは急激な切断によって波形が不連続になり、スピーカーから「プチッ」という微細なクリックノイズ（DCオフセットノイズ）が聞こえることがあります。ヘッドホン装着時のプレイで顕著になり、ゲームのプレミアム感を著しく損ないます。
*   **対策:**
    `osc.stop(stopTime)` を呼び出す直前に、Gainノードに対して `gain.gain.linearRampToValueAtTime(0, stopTime)` を適用して音量を数学的に完璧な0までスムーズに減衰させます。また、オシレーターが完全に停止した数ミリ秒後に、安全に `disconnect()` を実行する遅延ガベージコレクト（音声資源クリーンアップ）を徹底します。

### 3. 【UX】画面のズームやスクロールのロック漏れ
*   **問題点:**
    スマートフォン（特にSafariやAndroidの標準ブラウザ）で一筆書きをなぞっている最中、画面が上下にスクロールしてしまったり、ダブルタップと認識されてピンチズームが誤作動し、一筆書きの線がズレたり画面がブレたりするリスクがあります。
*   **対策:**
    CSSの `touch-action: none` をゲーム全体およびグリッドコンテナに徹底させると同時に、`pointerdown` および `pointermove` のイベントハンドラで明示的に `e.preventDefault()` を適用し、ブラウザ固有のオーバースクロールやバウンス挙動を完全にロックします。

## 🛠️ 3回目の修正方針
1.  **イベント委譲（Event Delegation）の導入**: `#grid-container` への一元バインドによりメモリリーク根絶。
2.  **ゼロクロスフェード Gain 減衰の実装**: 音響のクリックノイズを完全にカット。
3.  **ブラウザスクロール・バウンスの完全ロック**: WebViewにおけるドラッグの操作安定化。
