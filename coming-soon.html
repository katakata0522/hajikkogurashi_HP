⚡ FLAGSHIP PROJECT // UNREAL ENGINE 5 次世代インディー制作

鋭意制作中！

Corner Neighborは現在、Unreal Engine 5（UE5）を用いたインディーゲーム制作に挑戦しています。
これまでのブラウザミニゲーム制作で磨いてきた「直感的な手触り感」と「独自のユーモア」を基盤に、より深みのあるゲーム体験をお届けできるよう、一歩一歩丁寧に開発を進めています。

✨
DEVELOPMENT PILLARS // 制作の柱

私たちが今取り組んでいること

⚡ TECH ENGINE

Unreal Engine 5による表現

サークルの新たなステップとして、Unreal Engine 5を採用。リアルなライティングや手触りのある物理挙動を味方に付けながら、Corner Neighborならではの「温かみ」と「遊び心」が同居する世界観を構築しています。

🤝 JOINT DEV

とうぼうおじさんと共同制作

同じインディーへの情熱を分かち合う「とうぼうおじさん」とタッグを結成。アイディア出しやゲームメカニクスの仕様検討から、プロトタイプ検証・実装まで二人三脚で進行。「作っていて楽しく、遊んで最高に面白い」体験を妥協なく磨き上げています。

🎪 INSPIRATION

東京ゲームダンジョンでの熱狂

インディーゲーム展示イベント「東京ゲームダンジョン」に参加し、多くの開発者や熱心なプレイヤーの皆様から直に刺激とパッションを受け取りました。あの現場で体感した「インディーの自由さと熱狂」を、そのまま現在制作中のゲームへ注入しています。

🌱 等身大のインディーゲーム制作として

私たちは無理に大風呂敷を広げたり、過剰な演出を謳うことはいたしません。限られた時間の中で、仲間と一緒に知恵を絞り、一歩ずつ着実に面白いゲームの土台を築いています。日々の開発の試行錯誤や最新の進捗は、公式noteや公式𝕏にてありのままの言葉で共有していきます。
