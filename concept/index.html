SECRET BASE NOTEBOOK // 端っこメモ

「世界の端っこでゲームを作る」

Corner Neighborという名前は、部屋の片隅、教室の端っこ、世界の余白に居場所を見つけた仲間たちが集まったことから始まりました。
巨大なスタジオには真似できない、小さくても体温の宿るインディーゲームを、この秘密基地から世界中へ届けます。
