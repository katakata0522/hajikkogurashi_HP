## キャッシュ対策

PR #51の実装を `scripts/test-support/versioned-assets.mjs` へ共通化。漢字スライサー側は順序条件を追加する薄いラッパーにした。旧26ケースとライブ応答5ケースは維持。

`npm run sync:site` は共通ナビと内容ハッシュをHTMLへ静的に反映し、`npm run test:site` は同期忘れを拒否する。コメント・template・重複・非実行scriptなどで検査をすり抜けない。

ルート `.htaccess` のno-cacheはサイト入口の通常URLだけを対象にする。ゲームとCSS/JSのキャッシュ方針は維持。公開後の通常URL、再検証ヘッダー、MIME、全SHA-256一致は `npm run verify:site:live` で検査する。
