# Corner Neighbor 公開7ゲームのスマホ・PC点検（2026-10-11）

対象はミニゲーム広場に掲載されている9作品のうち、すでに別PR #56で改修中の「漢字スライサー・マージ」「LUMEN_MIRROR」を除く7作品。**この修正は独立したPRとし、既存2作品と混ぜない。**

## 判定基準

1. **何をすべきか分かる**：タイトル画面にルールと開始操作があり、始める前に読める。
2. **ゲーム盤が主役**：プレイ中のキャンバスと操作パッドを隠さず、スクリーンが画面外へはみ出さない。
3. **操作できる**：開始、戻る、タップ、長押し、キーボードを妨害しない。小さな画面では説明を減らすが、操作を隠さない。
4. **ゲームの個性を維持**：全作品を同じ見た目に統一しない。既存の色・モーション・ゲームロジック・スコア・保存キーは保持する。
5. **ゲームと端末の条件を分離**：画面幅・高さでUIだけを変更し、ルール・操作に関わる処理は共通にする。

## 検証実施

- リポジトリ `katakata0522/hajikkogurashi_HP` のmainを取得。ゲームHTML・CSS・JavaScript・既存テストの内容を確認。
- 7作品の既存Nodeスモークテスト成功（修正前・修正後）。CSS内容SHA-256先頭12桁による版数の一致を検査する新スモークテストも追加。
- Chromium 144 / Playwright（ローカル `about:blank` へ実際のHTML、CSS、JSをインラインで読み込み）で、**320×568 / 390×844 / 667×375 / 1440×900** のタイトル・プレイ中を撮影。ゲーム専用のフォントの外部読み込み、公開HTTPヘッダー、本番キャッシュ、サービスワーカーはこの方法では検証できない。
- 入力操作を実施：ブラウザ上での閉曲線ドラッグ（ブラックホール）、加速→ブレーキ（ギリギリ、走行中28km/h → BRAKE!!）、師範の手順表示／方向操作UI（影まね）、早押しによるお手つき（みきり）、仕分けタップ、長押し・解除（サボタージュ、スコア増加）、ジャンプ→ポーズ→再開（ウォールジャンパー）。いずれも確認したシナリオのページJSエラーなし。
- 影まね道場は師範の手本再生中に方向ボタンが無効なのが正常。入力可能状態への遷移後の全手順とクリアまでは本監査で未検証。
- 仕分け工場の早いタイミングのタップではプレイ状態が変わりうるため、入力イベントの網羅やゲーム難易度の妥当性は別途追加確認する。
- 新しい `scripts/seven-device-layout-browser-test.mjs` は、通常のlocalhost配信で4画面×7作品を実際のPlaywrightで調べる検証ゲート。実行環境のURLBlocklistにより**通常HTTP経由での実行は未完了**。ローカルのインラインChromium撮影はこれと混同しない。

## 本番公開までの残件

- 追加したPlaywrightの通常HTTP版をWindows/Linux上で実行し、フォント読み込み込みのスクリーンショットも確認する。
- Android Chrome・iPhone Safariで縦横切替、ブラウザアドレスバー伸縮、実タッチ、指2本操作、復帰を確認する。
- 7作品の難易度、クリア／敗北／再挑戦、音、保存の全分岐は今回のUI監査だけで「完全検証済み」としない。
- PR #56（2作品）およびサークル新トップPR #52との `scripts/run-minigame-tests.mjs` の競合をマージ時に解消し、総合回帰テストを再実行する。
